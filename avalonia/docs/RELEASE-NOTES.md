# Forterm Avalonia 0.3.0-alpha.36

这是独立 C# / Avalonia 迁移交付候选。旧 Electron、Go/Fyne 包与配置保留；不自动迁移、不调用 Go 后台。Windows 实机、原生文件对话框、真实系统凭据库和生产堡垒机仍需现场验收，不能把回环和交叉构建当现场成功。

- 连接导航最左、文件区左、中央终端/编辑、右侧资源监控；四区同时使用；明确选择已有文件协议来源，只隐藏对应文件协议顶部标签，解除最后关联后恢复。SSH 标签保留。
- 复用已认证 SSH transport；shell / SFTP / exec 权限拒绝分别提示，保留其他能力。默认15秒协议心跳，可设置5–600秒；不向终端注入命令或按键，不自动重新消费临时票据。
- 密码、私钥、多轮交互认证、已有 agent、最多4级保存跳板链；首次/变化指纹明确确认。临时凭据仅内存，精确参数转交与三秒内存去重。
- 原生编辑器、多草稿、1MiB UTF-8边界、BOM/换行保留、未保存确认、版本与完整SHA冲突检查、保存确认和另存新名。
- SFTP/FTP文件导航、懒树、队列、取消、上传下载、复制移动及目录操作。独立来源32KiB流式，约17MiB四种组合回环；只有同一FTP物理控制连接复制限16MiB。FTP不能保证原子覆盖时拒绝已有目标。目录不递归复制/删除。
- 权限有界递归预览/保留特殊位/逐项复核/部分完成计数。sudo复用独立SSH exec，需既有Python3、安全no-follow能力、策略允许且明确确认同路径空间；只在随机本次提示后询问一次本次密码，不安装组件。
- 监控默认手动，用户可开启3–600秒自动刷新；Linux只读指标来源可见，逐核环形仪表（两列虚拟化列表）/内存/磁盘/网络趋势、单飞、超时与隐藏暂停。exec被拒绝不影响终端或文件。
- 三向编辑器停靠、四区收起、分隔比例和主题字号导航持久化；快捷键帮助、会话切换/克隆/草稿关闭保护。小窗口大字号工具栏换行；中央编辑器最小正文高度，右侧监控内部滚动，队列26dp操作与完整tooltip。
- 独立堡垒机账户与本地TOTP、严格Base32/otpauth、遮蔽显示、当前周期复制、关闭清零。明确保存系统凭据，无明文回退。
- 配置无秘密导入导出，支持用户明确选择旧Go v1导出；生成新标识并重映射跳板，清除秘密标记和验证器启用状态，不导入指纹信任、不自动连接。连接删除保护跳板引用及凭据回滚。

## 本次本机文件工作区修订

- 本地终端启动后自动创建“本机”文件来源，默认从当前用户主目录读取本地文件和文件夹；文件面板不再显示远程文件通道空状态。
- 本机列表使用独立来源标识和路径边界，可刷新、进入子目录、返回上级并显示文件大小；不会把本机来源当成远程会话去关联或重新认证。
- 远程 SFTP/FTP 读取失败时仍保留“关联已打开的文件会话”入口，权限降级规则不变。
- 本机文件区增加懒加载目录树；展开目录只读取该目录下的子目录，点击树节点会同步刷新右侧文件列表，收起分支会释放节点。

## 本次按钮双向居中修订

- 通用Button及绑定的ContentPresenter明确水平/垂直双居中，分类按钮同步居中；保留原模板、对称padding、34dp普通按钮/30dp图标/26dp队列操作区域及悬停、按下、禁用、键盘focus状态。
- 图标和文字作为整体居中，统一6dp间距，原Content和自动化名称保持。低基线下拉字符改为内置矢量箭头，不加逐按钮负margin，不安装字体或引入图标库。
- 同尺寸实际代码修前后截图覆盖中英文13/14/16、深浅及100%/125%/150%软件渲染缩放；同时检查内容实测bounds、实际像素留白、连接底栏/顶部工具栏/分类/队列/确认弹窗与键盘操作。新版本实际Mac与Windows仍待协调复验。

## 继承的本地终端启动修复

- 修复正常“本地终端”按钮在新模板尚未完成初始化时读取终端行列数的空引用；等待模型就绪后启动。
- 工作区只由明确入口启动进程；默认控件的自动/手动并发启动合并为一次。关闭未初始化页会取消等待，异步创建返回时核对归属，读取任务固定捕获本次取消令牌。
- 保留真实启动失败和退出状态。Release诊断仅记录异常类型/调用栈，不记录参数、环境或异常消息。正确多行提示夹具在启动前写好，不依赖工具向终端输入复杂命令。
- 正常按钮/三种缩放场景、并发自动启动、初始化前关闭、无效可执行文件已做软件UI回归；冻结前完整结果另见验证报告。新版本原生GUI及Windows现场仍待复验。

## 继承的终端缩放修订

- 修复大→小→大时多行彩色长提示和右提示残留：活动终端保留原行边界，由shell/全屏程序按实际新尺寸重绘；不主动重排当前PTY输出。缩小时遮住的文字保留，恢复宽度可重新显示；擦除不会恢复旧尾。
- 同一布局事务按最终几何成对提交模型和PTY，避免中间尺寸反复重绘。PTY新绑定和异步启动同步当前网格，隐藏和零面积不发送过渡尺寸；SSH一格尺寸不再擅自变两格。
- 通过真实隔离zsh、两页PTY、stty回读、非回显输出/输入/选中复制、SSH WindowChange及alternate屏验证；没有操作用户当前终端，也没有在缩放时注入清屏、命令或按键。
- 优先匹配本机已有的等宽Nerd字体以覆盖Powerline样本；没有安装字体。缺少相应字体的机器仍需使用现有可覆盖字形的字体，不能由本机测试保证每台机器所有私有字形。
- 终端控件/模型采用同原NuGet版本的MIT固定源码小补丁，原文件SHA和差异随源码提供。新版本真实窗口/用户提示主题与Windows现场仍待复核。

## 三种 Windows 交付

1. 四入口 ZIP：完整解压到独立目录，保留所有DLL、资源和许可；不要只复制EXE。堡垒机控制器可配置其中的xshell.exe / xftp.exe，参数保持原样。
2. 当前用户安装包：按版本独立安装目录与开始菜单，不覆盖旧版本；卸载只删除本包列出的文件，保留未知文件、用户配置与系统秘密。
3. 便携 EXE：C# self-contained单文件内嵌同一完整ZIP，验证SHA后释放到本次独立临时目录，使用ArgumentList原样转交参数，等待主进程退出后清理。无需安装.NET或VC++运行库。用户元数据仍存本用户独立应用数据目录，不随临时运行时删除。.NET单文件启动器自己的原生库使用标准本用户提取缓存。需要稳定四入口路径时使用ZIP或安装版。

正常运行时不含PDB；符号包另存。应用self-contained，不裁剪，运行时与第三方许可随包提供；静态导入检查不代表干净Windows运行通过。面向Windows10 1903及以后x64 / Windows11，当前版本未做Windows实机验收，不能作兼容性保证。

不支持/待验证：生产门户登录与资产接口契约缺失，不能在应用中自动登录门户；真实堡垒机通道策略、Windows性能/IME/高DPI、系统picker与vault、受限agent/证书硬件类型仍待。SFTP目录路径SETSTAT无inode/CAS强排他，普通FTP无通用排他/原子替换保证；不静默降级。
