# Forterm Avalonia 0.3.0-alpha.36

独立 C# 重写，正常应用没有 Go 后台或 WebView。旧 Electron/Go 与 alpha.1–14 检查点、配置和用户窗口保留。当前为功能迁移交付候选，外部验收和协议能力边界见 docs/MIGRATION.md。

构建使用 global.json 固定的 .NET SDK10.0.403，独立 SDK 位于 /Users/xianyu/.cache/forterm-dotnet。运行 dotnet build src/Forterm.Desktop；测试 dotnet test tests/Forterm.Tests。合成 SSH/SFTP/agent 服务只绑定自有127.0.0.1，不访问生产、历史票据或用户 agent。

tooling/publish.sh 发布 self-contained Mac arm64 和 Windows x64 四入口，tooling/package-checkpoint.py 冻结不可覆盖的阶段包和源码。正常包排除 PDB，符号另存，保留全部运行 DLL 和许可。静态原生导入检查不代表干净 Windows 已运行；tooling/package-windows.py从同一冻结ZIP构建NSIS当前用户安装器和C# self-contained单文件便携入口，逐文件比对并核对便携内嵌原ZIP；最终产物及证据见release，Windows现场仍待。

默认独立元数据 Forterm/AvaloniaAlpha36，FORTERM_AVALONIA_DATA 可指定隔离目录；目录也参与当前用户 IPC 命名。不自动读取旧配置。临时票据只在内存、三秒 HMAC 去重、不自动重登或回填。四入口参数用 ArgumentList 精确传递。首次指纹明确确认、变化单独确认；测试连接不写信任库。

密码/加密私钥/多轮 KI、已有本机 agent、最多4级保存跳板链已接。agent 只请求公钥和签名，不启动服务、不导出私钥；受限 session-bind/证书/硬件类型尚不承诺支持。跳板复用已认证 direct-tcpip，私有 loopback relay 有随机认证且限定目标。每个能力独立通道与引用计数。

SSH want-reply 保活默认15秒、可设5–600或关闭；只有一个未确认请求，三个间隔窗口无应答即停止，不自动重登。已打开 SFTP 只读保活单飞8秒超时，只停止文件通道。偏好对新连接生效；主题/字号/导航持久。

同一工作区终端、文件、在线编辑和监控可同时展开、分别收起，支持拖动分隔；SFTP入口也可按需打开同认证终端。文件上下传与编辑保存共用串行队列，固定原来源和路径，同目录私有临时项、完整 SHA/版本复核、明确确认后原子提交。覆盖需服务器 posix-rename，拒绝删除再改名。SFTP v3 没有 inode/CAS，元数据和哈希复核仍不是服务端原子比较交换。

原生 AvaloniaEdit 编辑最多12份远程草稿，只接受不超过1MiB的 UTF-8普通文件（保留BOM及LF/CRLF/混合换行），拒绝二进制、链接与特殊文件。Ctrl/⌘S 明确确认后排队，冲突保留草稿；来源关闭只读，不改投其他来源。内容仅内存，不用本地明文临时文件。关闭草稿/会话/应用提示未保存项。

监控默认手动，用户可开启3–600秒自动刷新（默认3秒）。在当前 SSH 上开独立 exec 运行固定只读 Linux /proc 与 df 命令；不安装agent，不往交互终端输入命令。8秒可见截止、单飞与合计1MiB输出上限；未结束的通道开通仍持有防重叠锁直到收尾。隐藏/切页/移除暂停并取消当前请求，恢复时重置delta；CPU/网络首样和回退显示未知，逐核/环/最多60次速率趋势来自实际响应。exec受限或非Linux不伪造指标，其他能力保留。

系统凭据只有显式勾选才进入 Credential Manager/Keychain API，无明文回退。当前测试使用假保管库，真实 OS 凭据读写未验。软件渲染图、合成协议回环不等于原生窗口、物理高DPI/IME、Windows实跑或生产验收。真实GUI由经理协调，不抢前台。

alpha.11：文件视图按来源独立，明确关联已有文件会话，不按主机名自动匹配或认证。只隐藏被其他工作区关联的FTP/SFTP协议顶部页；SSH页保留，解除最后关联或关闭所属工作区后恢复。循环仍保留可达顶层。解除关联只移除借用视图，不关闭原来源、清除草稿或取消既有绑定任务；原来源关闭则取消其任务并让相关草稿只读。来源标题进入草稿标签/保存确认。

目录树从更多菜单展开，按需读取普通子目录，不跟随链接；每路径单飞/8秒，缓存最多128目录及50000项，单目录20000项，树4096节点/128层；收起丢弃视图节点，旧回复不再填回。路径栏导航保留，拒绝不安全名称。

alpha.11：FTP父目录逐级LIST复核并拒绝链接；SFTP初始化REALPATH仅在明确PermissionDenied/OperationUnsupported时保留未知CWD的文件通道，超时和其他错误仍拒绝。未知CWD不猜根目录、不发文件探测；用户明确确认已知绝对目录并成功LSTAT/LIST后才允许操作和只读探测。授权仅内存，来源固定。

文件区右键提供复制/剪切/粘贴、新建目录、改名与删除；聚焦文件列表的Ctrl/⌘C/X/V使用应用内文件剪贴板，路径栏和编辑器仍正常文本操作。跨来源复制限16MiB普通文件，不递归目录，不覆盖同名目标；移动只在目标提交确认后复核并删除源，源变化/取消/删除未确认明确报告部分移动，不自动重试。目录仅创建/改名和删除空目录，删除须确认。SFTP目录创建时0700，FTP遵循服务器权限策略。

复制能力阶段限制（完整迁移尚未对等）：当前alpha.11所有复制使用最多16MiB内存，不等于旧Go能力已全部迁移。旧Go仅同一FTP控制连接复制受该限制；后续恢复SFTP及独立跨源32KiB有界流式/中转、无额外认证、有序资源预留、身份/SHA/取消/源变化保护，并测试大于16MiB。当前同名一律拒绝也只是阶段限制，SFTP安全覆盖选择仍待；FTP没有原子保证时保留拒绝。

alpha.11 收敛复制对等：SFTP及独立SFTP/FTP来源之间使用32KiB缓冲流式复制，不整文件入RAM或落本地中转；两端资源按稳定顺序预留并逆序释放。仅同一FTP物理控制连接的复制保留16MiB已清零缓冲限制；同资源移动采用已核对改名，可移动大文件。FTP兄弟视图共享物理资源，不自动另登。

已有SFTP目标提供明确覆盖选择，固定旧版本并在提交前复核，仅服务端posix-rename支持时替换；复制保留旧目标权限，原地移动保留源权限。FTP无通用安全替换时仍拒绝。实际17MiB四种独立协议组合、单FTP限制/大移动、SFTP大移动覆盖、取消保旧/源与目标变化/有序双向预留已回环。旧alpha.8“全部16MiB/同名一律拒绝”是历史阶段限制，以此节与迁移矩阵当前状态为准。
