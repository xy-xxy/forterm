# Forterm Native 0.2.2-dev.10 — 连接卡片界面与滚动修订

这是正常完整应用候选，保留 dev9 的终端、文件、编辑、监控与认证能力。原有 dev9 包及用户会话不变。

本次只围绕用户的连接编辑参考图与“滚得到但不到底”反馈修改原生界面：

- 左侧四类导航定位同一份输入，右侧圆角分组卡片；居中标题、关闭入口、底部独立测试/取消/仅保存信息/保存并连接。
- 地址端口同排，用户密码同排；14dp主文字、12dp辅助说明、约32dp输入高度；深浅主题，窄窗口改顶部导航、卡片行上下排列，底部按钮换行。
- 专用滚动条留白与上下边距。私钥展开/收起、主题和窗口宽度变化后先重排再测量完整高度；不放大根容器或隐藏末项来规避问题。
- 修复鼠标在输入框上时纵向滚动被内部水平滚动容器吞掉；输入框仍保留水平光标跟随。
- 原生焦点遍历会把当前表单字段带入视口，不靠周期定时器或注入Tab。16问题认证及权限窗口共享同一表单视口。
- 密码仅本次/系统保存/清除旧密码、保存失败保留输入、仅保存确认丢弃、保存并连接、显式连接测试取消与认证边界均保留。状态长文本可用右侧信息按钮完整查看。
- 没有添加未实现的代理/编码/初始化假开关，没有自动安装/执行命令，没有新的生产登录或上传。

验证与限制：软件驱动实际命中滚轮、轨道/拖动、分类定位、Tab遍历和窗口缩放；末项、独立footer及gutter边界有断言；深浅/短窗口/150%/窄布局有截图。详见 docs/NATIVE-DEV10-DELIVERY.md 与 evidence/dev10-final-race.log。Mac候选正常 cmd/forterm，尚未启动给用户；Windows仅交叉编译。软件驱动不代替系统鼠标/高DPI/原生系统文件选择器或生产验证。

正常应用多版本共用实例IPC。若dev9仍运行，新入口可能转交给旧进程；不能把旧窗口当成dev10。由用户保存退出旧版后切换，或由经理明确隔离目录并行验证。不得强关现有会话。
