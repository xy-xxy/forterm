# Forterm Native 0.2.1 Windows现场验收

本机为macOS arm64。已实际原生窗口/本机协议/系统钥匙串与交叉构建；下面必须由Windows10/11 x64实机完成，不能勾成已验。

1. 安装程序默认独立 `%LOCALAPPDATA%\Programs\Forterm Native`，开始菜单/桌面/卸载项独立；旧Forterm、旧配置、现有Xshell/Xftp入口不被覆盖。安装、启动、重复安装、退出/卸载后原生配置和凭据保留、旧版仍可运行。
2. 完整四入口ZIP同时是便携目录。独立解压后直接运行，不要求Chrome/WebView2/Node。测试无管理员权限路径、中文/空格目录、重启和多实例精确参数/当前用户SID私有管道隔离。
3. 本地PowerShell/ConPTY、UTF-8/CJK/组合/emoji、Ctrl-C/箭头/选择复制/输入法、多行全量预览确认/取消/bracketed paste、resize与备用屏幕。
4. 先用测试SSH/SFTP/FTP与新签发控制器凭据。校验参数一次解码、空密码形式、临时票据仅内存/不进库/不自动重连。分别拒绝shell/SFTP/exec应保留其他能力；5–600秒心跳快照与仅已开SFTP探测，无终端输入注入。
5. 同窗四区、双终端输入隔离、多个文件来源同名dirty草稿、解除关联与共享源关闭/最后引用恢复。源绑定保存不能随当前浏览来源变化。
6. 普通大文件（含>1MiB）、25+批次/追加、排队/活动取消/停滞/元数据超时/失败停止其余排队、原本地文件/临时文件与远端部分文件提示。NTFS及可移除文件系统的独占下载提交。
7. 文本BOM/LF/CRLF/尾空格/混合换行明确转换、1MiB文本边界、首存排他/保存确认/双冲突/unknown-result草稿保护。FTP在线编辑仍明确不支持。
8. 文件右键/菜单/双击、目录创建/改名/非空并发删除/链接边界/权限特殊位保持与应用后核对；运行/排队相关路径不允许破坏操作。
9. 系统凭据管理器：明确保存密码/私钥口令/TOTP key，JSON/导出无秘密，清除/删除/导入新ID不复用旧秘密；旧safeStorage不作假兼容。主机指纹首次/变更确认、加密key/Agent/跳板每跳指纹。
10. 深浅主题与字号/导航/宽度/方向/双分屏/窗口尺寸立即关闭恢复；100/125/150% DPI、窄窗、源标签/工具栏/队列和更多菜单鼠标/滚轮/Tab/Enter可达，键盘分隔Home/End/Shift/Reset。

厂商门户登录/资产API仍缺脱敏契约，原版也未接通；这不是本原生版本可以现场勾选的能力。未签名，未发布/推送。

11. 在150%系统缩放下将窗口调整至约1050×650物理像素：两文件来源、27文件/25队列、编辑与终端/监控同时开启。文件区滚动可抵达末文件并选择；滚到展开队列后可滚到第25项/打开详情，再返回路径工具。来源/工具不被进度条覆盖；代码可见且可输入/撤销，恢复常规尺寸后源/草稿/队列保留。
