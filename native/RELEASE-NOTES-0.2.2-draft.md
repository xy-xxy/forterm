# 0.2.2 更新说明草稿

尚未正式发行；当前审查候选为0.2.2-dev.2。Windows普遍按钮延迟尚待当前构建实际交互验收，不能承诺已完全解决。

- 减少终端画布对象和无变化刷新，合并有界输出；精确字宽保留长ASCII行/中文宽格对齐，历史缓冲循环复用，减少滚动分配。
- 连接库改虚拟可见行，连接树缓存索引；配置快照不再做JSON深拷贝。显示使用已提交metadata，凭据/磁盘慢操作不挡住显示读取；实际登录仍在事务门内取得一致realm和凭据。
- 偏好和导入导出持久化放后台；紧凑中性深浅主题、清晰空工作台、细边框及短窗口可滚动弹窗。
- 上传路径未确认时明确说明原因；REALPATH拒绝不再只显示模糊文案，可明确确认后按绝对路径读取。修正Windows文件URI，保留中文、空格和字面百分号；失败计数和队列错误更可见，来源/目录仍绑定选择时快照。
- 保留四入口精确参数转交、去重、临时凭据仅内存、不自动重用票据/重登，及终端/文件/代码/监控同工作区。

验证边界及旧版本保留情况见 `docs/NATIVE-REVIEW-DEV2.md`。最终安装器、ZIP、便携及校验值在独立复核收敛后形成；此草稿不替代正式发行说明。
