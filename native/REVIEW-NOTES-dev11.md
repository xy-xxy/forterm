# Forterm Native 0.2.2-dev.11 — 原生连接按钮修订候选

保留dev10原包和用户正在使用的dev9窗口。本候选正常cmd/forterm，不是预览或WebView，尚未启动GUI。

- 连接底栏统一34dp高、6dp圆角、约16dp横向内边距与14dp正文；测试连接最小120dp、取消80dp、绿色主操作144dp。次按钮透明底细描边，图标与文字有独立间距。
- 左侧测试/运行时取消测试，右侧取消、保存并连接和带描边下拉；仅保存信息通过“更多保存方式：仅保存信息”提示与原生菜单发现，保留丢弃未持久化密码的确认，不新增秘密保存。
- 底栏按实际可见按钮所需宽度换行，测试运行时也检查边界。关闭、完整状态、保存菜单采用30dp图标命中区、明确可访问名称和提示文字。
- 默认/悬停/按下/禁用/键盘焦点有不同外观；原生按钮保留可访问角色，Enter/Space触发、禁用拒绝、焦点可见。提示文字留在现有弹窗对象树，不新建焦点层；菜单向上展开，Escape保留输入、方向键+Enter进入仅保存确认。
- 保留dev10滚动到底、独立gutter、展开/收起/焦点揭示、深浅与窄窗规则；保存验证、密码策略、显式连接测试/取消/单飞不变。
