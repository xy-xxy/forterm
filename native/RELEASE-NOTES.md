# Forterm Native 0.2.1

首个完整原生工作区候选：Go/Fyne自绘界面取代浏览器内核，保留原0.1.7 Electron版本和配置。沿用户认可的深浅紧凑工作区继续完善，终端/文件/代码/监控、多来源关联、流式队列、文件操作、连接库与系统安全存储均迁移到Go实现。

安装版使用独立 Forterm Native 目录和卸载标识；四入口ZIP同时作为可解压运行的便携目录。不会导入Electron安全存储密码或历史临时票据。生产使用前请完成Windows现场清单，尤其ConPTY、中文IME/DPI、系统凭据、控制器参数和安装卸载。当前验证不能表述为Windows原生运行全部通过。

普通文件传输无原型1MiB限制，在线文本编辑仍限制1MiB并保留安全边界。FTP在线编辑、厂商门户登录仍不提供，明确提示原因。失败/取消不自动重传或重新登录；目录删除已完成的部分不可回滚。

选择文件协议来源后自动展开文件区，与当前终端同时显示；仅隐藏对应的顶部重复标签，解除关联恢复。编辑器支持左/右/底部停靠，导航宽度支持拖动、键盘和重启保存。

0.2.1 修复150%缩放、1050×650物理小窗口中展开队列覆盖文件导航/工具栏、文件行与代码正文无法抵达的问题。文件区使用有明确滚动条的滚动列，队列在独立150dp区域内滚动；短窗口为代码分配可用高度，文档工具/正文在裁切滚动区域中保留，避免负尺寸。实际滚轮/末文件选择/第25项详情/代码粘贴撤销/恢复常规窗口已验证。0.2.0旧包保留但不推荐使用。
