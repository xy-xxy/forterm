# Forterm Studio 0.4.0-alpha.8 交付说明（2026-11-24）

补齐参考截图“系统配置”里还没做的几类：编辑器、文件管理、上传下载、布局、按键配置、备份恢复，另加监控阈值。计划和决定见 `docs/STUDIO-REBUILD-PLAN.md`，上一版见 `docs/STUDIO-ALPHA7-DELIVERY.md`。

Core 和 vendor 的 SSH.NET 有增量改动，默认行为不变（见“改动范围”）；`Forterm.Desktop` 的源码、alpha.7 及更早的包和检查点都没有改动。

## 内容

### 空闲保活（用户 11-24 提出）

- **用途**：有的堡垒机和服务器按“多久没有键盘输入”断开会话，协议心跳对它们不管用。打开后，一段时间没有输入就自动向终端发送一次输入。
- **默认关闭**。开关在系统配置 → 通用终端 → 空闲保活；打开后对所有 SSH / Telnet 会话生效，**包括控制器唤醒的会话**——这是“唤醒会话不自动写入任何内容”这条约定的唯一例外，由用户决定，已记入计划。也可以在终端右键菜单或命令面板里只对某个会话开关。
- 生效时状态栏右侧显示“空闲保活 4 分钟 · 2 次”，点一下就只在本会话关闭。到时间却没有发送时显示“暂缓”，鼠标停上去说明原因。
- **计时**：按这个终端实际发给服务器的内容计时；本机快捷键没有发送内容，不算。默认 4 分钟，可选 1–30 分钟。
- **发送的内容**：
  - 空格 + 退格（默认）：命令行里看不出变化。正在等待单个按键的程序（“按任意键继续”、more、git log 的分页）会收到一个空格。
  - 空字符：多数程序忽略。
  - 回车：bash 的 `TMOUT` 只认回车。只有同时满足这几条才发送：光标停在命令提示符（以 `$`、`#`、`%` 结尾）后面、后面没有别的内容、没有输入到一半的内容、上次检查之后终端没有新的输出。识别不出提示符就不发送。
- **不发送的情况**：全屏程序（vim、less、htop、tmux）占用屏幕时，除非另外打开“全屏程序里也发送”；用户离开超过最长时间（默认 8 小时）；会话断开或 shell 已经结束；本地终端。不会自动重连。
  - 只有用户自己的键盘、粘贴、鼠标、快速命令算“用户在”。终端自动应答、连接设置里的初始执行和保活命令不算。
- **要么立刻发出，要么这次不发**：服务器没有在接收输入，或者有别的内容正在发送时，跳过这一次，不会排队晚到。
- 从别人的备份文件恢复设置时不会打开它。

### 内置编辑器

- **查找和替换**：macOS `⌘F`、其他系统 `Ctrl+F`（也可用“查找”快捷键）；替换 `⌘⌥F` / `Ctrl+H`。区分大小写、全字、正则；匹配处全部标出，当前一处加框，显示“第几处 / 共几处”，编辑时跟着更新。
  - 全部替换算一步撤销；普通模式下替换内容按原文，正则模式支持 `$1`。
  - 正则用 .NET 的非回溯引擎，写得再怪也不会卡住；不支持前后查看和反向引用，会直接说明。最多标出 1 万处。
  - 编辑器组件自带的查找面板（英文、正则没有时间上限）已停用。
- **跳到行**：`Ctrl+G` 或点状态条的行列，支持 `120`、`120:8`、`-1`（从末尾数）。
- **状态条**：行列、选中的字符数和行数、总行数和字符数、自动换行开关。
- **设置**：字体、字号（也可以按住 Cmd / Ctrl 滚动滚轮）、自动换行、缩进宽度、Tab 插入空格、行号、显示空白、关键字颜色总开关。
- **记住语言**：手动选过的语言用于同类文件（按扩展名，没有扩展名的按文件名），最多 100 种，可以全部忘掉。

### 快捷键可以改

- 系统配置 → 快捷键：点一下，再按新的组合；可以单个恢复默认、停用，也可以全部恢复。改完立即生效，提示和菜单里的显示一起变。
- 不能用属于终端程序或系统的组合，并写明原因：单独的按键、Ctrl+字母、Alt 组合、Windows 上的 Ctrl+Alt（就是 AltGr）、`Ctrl+Shift+-` 等、复制粘贴、`⌘Q` 之类；和别的快捷键重复也会提示。
- Windows 上 `Ctrl+Shift+F` 和微软拼音冲突时，可以把“查找”换成别的。

### 文件

- 文件栏显示**大小和修改时间**（够宽时），鼠标停在文件上显示完整路径、字节数和时间；目录总在前面。
- **排序**（名称 / 大小 / 修改时间 / 类型，可反向）和**隐藏文件**开关，在文件栏工具条和系统配置里是同一设置；切换时不向服务器请求，选中项保留。
- 隐藏只影响显示：下载、删除、压缩文件夹时都包含隐藏文件（有测试）。
- **默认下载目录**：右键菜单里不询问位置的那一项（原“下载到桌面”）可以改到别处；同名自动编号，不覆盖。
- 传输完成的提示可以关；失败总会提示。

### 布局

- 新打开的 SSH 会话默认显示哪些栏（文件、监控）；恢复默认栏宽。

### 监控阈值

- 磁盘、CPU、可用内存、负载的“注意”和“严重”分别可调。只影响本机显示，不发送任何内容。

### 备份恢复

- **备份**：设置、快速命令、连接、分组、隧道存成一个文件。不含密码、私钥口令、动态令牌种子、会话环境变量和主机指纹；文件权限仅本人可读写（macOS / Linux）。
- **恢复**：先显示会做什么，再确认。已有的连接和快速命令保持不变，只添加缺少的；分组按路径合并；本地端口被占用的隧道不添加；设置整体替换，原文件改名为 `preferences.before-restore-时间.json`。
- 文件可能来自别人，所以默认**不恢复会自动执行或影响本机的内容**：连接的初始执行、保活命令、算法偏好，本地终端程序，默认下载目录，以及“关闭粘贴确认”。只有勾选“这是我自己做的备份”才恢复，每次都要重新勾。
- 备份文件里含有任何秘密字段、内容不完整、互相引用不成立，都整体拒绝。

### 说明更正

- 系统配置里的“会话保护”写清楚了实际的保活方式：SSH 协议心跳默认 15 秒，SFTP / FTP 同样间隔做只读查询，都不向终端输入内容；**Telnet 没有协议心跳**；心跳不能代替键盘输入，按空闲时间踢人的堡垒机仍可能断开会话。

## 修复的原有缺陷

以下在 alpha.7 及更早就有（第 1 项在 SSH 库里，alpha.36 也有；alpha.36 已冻结，没有改）。

1. **服务器一段时间不读输入时，整段输入会重复发送。** 粘贴给慢速设备，如果设备超过连接超时（默认 45 秒）没有读，SSH 库放弃发送但不清空自己的缓冲区，下一次按键会把整段粘贴再发一遍，界面上没有任何提示。现在 Studio 的终端输入直接写进通道，每个字节只发一次；服务器不读就一直等，关闭终端或断线时立刻结束。
2. **两处同时写一个终端会互相打乱。** 初始执行、保活命令、“CD 到终端”以前不经过终端自己的写锁。现在一个终端的所有写入排队进行。
3. **切换到别的会话会丢掉文件列表的选中项**，期间或回来之后上传可能传到 `/`；后台会话的 pwd 跳转也会让列表选错行。选中项现在由会话保管。
4. 刷新失败、点“空目录”那一行、默认目录不存在时，当前目录变成 `/` 或与路径栏不一致；右键菜单打开时 pwd 跳转会换掉选中的行；`/home` 会被当成 `/ho` 的下级。
5. 删除、刷新后列表跳动、键盘位置丢失（再按方向键会跳到别的按钮）。
6. 一个连接的第 10 个通道（终端、文件、监控合计）会永远等待，没有提示。上限改由服务器决定。

## 未验证 / 限制

- 以下都没有运行过：Windows 实机（ConPTY、DPI、输入法、AltGr、真实拖放）、真实控制器唤醒和堡垒机、真实 OpenSSH、Windows 凭据管理器和 Mac 钥匙串的真实读写、屏幕阅读器。
- **空闲保活没有在真实的堡垒机上验证过**：有的堡垒机可能把这种输入也记入审计，或者按别的规则判断空闲。使用前请确认单位的规定允许。
- 回车方式只认 `$`、`#`、`%` 结尾的提示符；`❯`、`>`、右侧带提示（RPROMPT）等识别不出，不会发送。没显示过的会话不知道屏幕内容，也不发送回车。
- 正在读取单个按键的程序会收到默认方式的空格；全屏程序的判断只看备用屏幕。
- 服务器一直不读输入时，粘贴会一直等到关闭终端；没有“取消这次粘贴”的按钮。
- 文件的修改时间：FTP 服务器不说明时区时按 UTC 处理。
- 编辑器的正则不支持前后查看和反向引用。
- **退回 alpha.7**：alpha.7 能读取设置文件，但一旦保存会丢掉本版新增的设置。
- 其他限制见 `docs/STUDIO-ALPHA4-DELIVERY.md` 到 `docs/STUDIO-ALPHA7-DELIVERY.md`。
