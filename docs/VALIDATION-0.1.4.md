# Forterm 0.1.4 验证记录

环境：macOS arm64、Electron 45、捆绑 Node.js 24。测试使用独立临时 userData、合成连接列表和本机回环 SSH/SFTP，没有生产请求或真实认证信息。

## 缺陷与修复

独立复核指出：0.1.3 在 1050×650 窗口、150% 页面缩放下 CSS 视口高 412，侧栏 clientHeight=412、scrollHeight=478、overflowY=visible；导入/导出及主题按钮越出视口，根 app 隐藏溢出导致无法操作。此前仅检查外框和无横向溢出不足以验收。

0.1.4 固定导航和主题栏，为连接列表与工具区分配独立、可聚焦的滚动区域；增加低高度紧凑样式。窄布局工具栏也使用可聚焦横向滚动。欢迎页与纯 SFTP 页面建立完整滚动路径。

新增测试还发现文件/监控并排时，“刷新状态”所在区域虽然有正高度，却比完整按钮更矮。已调整工作区高度预算与分隔比例下限；文件与监控区域至少容纳 44 CSS 像素，空间极小时通过设计的滚动区域保留访问路径。

额外组合回归复现：150% 下展开六条传输记录时，上方工作区被挤到无法点击刷新。已将传输抽屉最大高度限制为 min(180px,20vh)，让队列内部滚动；同一场景的刷新、编辑内容与显式保存、清理记录均已实际点击通过。

## 控件级检查方式

新增回归记录 99 次控件检查，不仅检查容器：

- 控件矩形必须完整处于 CSS 视口内、所有有裁切行为的祖先内；中心点 `elementFromPoint` 必须命中自身或子元素。
- 允许在明确的 overflow:auto/scroll 容器中滚动到控件；不允许程序滚动 overflow:hidden/clip 的根或非用户滚动祖先来掩盖缺陷。
- 125% / 150% 分别测试空列表与 40 多条保存连接；连接列表和工具区实际接收 PageDown，Tab/Enter 和鼠标可操作。导入入口通过聚焦工具区后发出真实 Tab 序列到达，再按 Enter 触发。
- 主题切换通过鼠标及 Enter 实际往返；导入/导出调用隔离进程的原生文件对话框，初始导入取消，长列表导入读取合成 JSON，导出实际写入临时 JSON。无生产文件写入。
- 打开帮助、新建连接与心跳设置，检查滚动后的底部保存及关闭按钮；编辑长列表末尾连接并保存。
- 实际打开回环 SFTP，访问纯文件页面工具；同会话打开终端、文件、编辑、监控，在比例 Home/End 极限下访问上传、刷新和自动刷新；显式保存编辑内容并比对临时文件。
- 分屏后实际访问并点击方向、重置、面板开关，检查窄工具栏；恢复 1440×940、100% 后再次验证主题和导入导出。
- 所有鼠标/键盘操作没有向 SSH shell stdin 注入字符，只有一次 SSH 认证。

150% 长列表样本：视口 700×412；app 和 sidebar 的 clientHeight、scrollHeight 均为 412，scrollTop=0；工具区 clientHeight=131、scrollHeight=187，用户滚动到 scrollTop=56 后，导入/导出矩形 y=347.83、height=17.33、bottom=365.17，完整位于视口内。主题按钮 y=385、height=16、bottom=401，保持在固定底栏，未越出高 412 的视口。原始逐控件值及滚动位置见 JSON。

最终增加队列高度限制后重新通过类型/构建、控件级可达性及实际指针布局回归。统一工作区回归在本轮此前通过；协议测试未重复运行。
