# Windows 控制器验收

请使用新申请的临时会话。验收报告中只记录脱敏结果，不粘贴 Cookie、Token 或密码。

1. 解压 ZIP 后，双击 `forterm.exe`。检查中文界面、连接列表和“本地终端”，运行 `Write-Output 'Forterm local test'`。
2. 控制器 Xshell 路径指向 `forterm-diagnose.exe`。申请会话，检查参数是否已识别并导出报告。诊断期间不应新增远程连接。
3. 将 Xshell 路径改为 `xshell.exe`，申请新会话。核对 SSH 主机指纹，完成密码 / 验证码流程，确认进入的是被授权目标资产。
4. 在主窗口打开时再次申请会话。验证新增标签、原会话不受影响；用 `-newwin` 验证独立窗口。
5. 检查中文、复制粘贴、窗口缩放、vim/top、Ctrl+C，以及终端分屏与搜索。
6. 控制器 Xftp 路径改为 `xftp.exe`，重新申请 SFTP 授权。验证列表、小文件上传 / 下载、覆盖确认、取消、重命名和删除测试文件。
7. 在禁止 SFTP 的资产上打开文件浏览，确认出现权限说明但终端仍可输入。监控被禁止时也应如此。
8. 断开或等待临时票据过期后，不应自动重连。回到控制器新建授权后应能建立新会话。
9. 检查导出的诊断 JSON、连接 JSON 和本地配置，临时密码不应出现。没有显式选择保存的手动密码也不应落盘。
10. 关闭全部窗口后重新打开，保存的连接仍存在；临时会话不自动恢复。
11. 使用相同票据在三秒内连续启动 11 次：诊断模式只显示一张报告且调用数为 11；真实入口只创建一个终端。换一张票据时应创建独立会话。

如果显示“需要适配”，保留脱敏报告。诊断中的未知值默认隐藏；只在必要时额外说明具体选项名，避免提供实际秘密值。

## 0.1.2 同一会话工作区

- [ ] 从 Xshell 打开终端后，启用文件浏览、打开文本编辑、手动监控；确认没有重复登录提示。
- [ ] 从 Xftp 打开文件后，点击“在此会话打开终端”；确认 shell / SFTP / 监控并行可用。
- [ ] 堡垒机拒绝 SFTP、shell 或 exec 时，确认其他已授权通道继续工作，提示清晰。
- [ ] 默认 15 秒心跳；设置后新会话生效，旧会话快照不变；终端没有自动回车或命令。
- [ ] 文本读取 / 编辑 / 保存 / 多文件切换；CRLF、UTF-8 BOM 文件；大文件、二进制、无权限文件拒绝。
- [ ] 远程另一个程序修改文件后保存，确认冲突提示、远程内容未被静默覆盖、本地草稿保留。
- [ ] 关闭编辑器、会话、窗口时未保存确认；取消关闭后草稿可继续编辑；断线后可复制草稿。
- [ ] 确认服务器支持编辑临时文件替换，原普通权限位保留；重要 ACL / 所有者文件不要直接在线替换。
- [ ] 监控自动刷新仅用户启用，切走或收起后停止新请求；异常不影响终端。
- [ ] 文件筛选 / 排序 / 隐藏文件 / 路径导航；下载取消保留原本地文件，传输记录可清理。
- [ ] 主题、字号与分组折叠重启保留；上下 / 左右分屏；1050×650 窗口可滚动操作。

## 0.1.3 可拖动布局

- [ ] 拖动连接栏、文件/监控侧栏、编辑器、文件与监控比例、上下/左右终端比例；拖出分隔条后松手仍正确结束。
- [ ] 取消拖动、切到其他应用、拖动时窗口变小，没有卡住的鼠标样式或后续误拖；触摸/笔输入如需使用请单独验收。
- [ ] Tab 聚焦分隔条，方向键 / Shift / Home / End / Enter；双击与顶部重置布局可用。
- [ ] 拖动时远端全屏程序尺寸同步，慢速 shell 打开后无需再次拖动即可获得当前尺寸。
- [ ] 正常重启、立即关闭后重开、缩小再放大、收起/展开，偏好大小和两个终端方向的比例保留。
- [ ] 编辑器收起保留未保存草稿，展开恢复高度；拖动没有向终端发送字符、保存文件或再次认证。
- [ ] 文件导航/筛选在切换监控和收起侧栏后保留；自动监控隐藏暂停、展开恢复，不叠加请求。
- [ ] 展开传输队列、1050×650 最小窗口、Windows 显示缩放下各区域仍可操作；必要时内部滚动、收起编辑器。

- [ ] 连接列表和工具区分别滚动，末尾连接可编辑；导入/导出可用鼠标滚轮或聚焦后 PageDown/Tab/Enter 到达并操作。

- [ ] 编辑器打开、文件/监控比例拖到两端时，刷新、自动刷新、在线保存可以完整滚动到并点击。
- [ ] 分屏后窄布局工具栏可横向滚动，方向、重置、侧栏开关可用；恢复正常窗口后没有丢失入口。

- [ ] 150% 下展开至少六条传输记录，队列自身滚动；监控刷新、编辑内容、显式保存及清理记录可实际操作。
