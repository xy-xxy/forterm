# Forterm Studio 0.4.0-alpha.5 交付说明（2026-11-23）

对照参考截图 12–14 补齐“系统配置”。其中搜索、导航栏颜色、系统字体原本就列在计划里，之前没有做。计划和决定见 `docs/STUDIO-REBUILD-PLAN.md`，上一版见 `docs/STUDIO-ALPHA4-DELIVERY.md`。Core、vendor 和 alpha.36 都没有改动；alpha.4 及更早的包、检查点也没有改动。

## 内容

### 搜索设置

- 左侧分类上方加了搜索框。按标题和关键词同时筛选分类和分类里的卡片，例如搜“字体”，只留下“系统字体”“终端字体”“终端字号”。
- 当前分类没有匹配项时，自动切到第一个有匹配的分类；完全没有匹配时显示“没有匹配的设置”。清除按钮恢复全部。

### 主题界面

- **导航栏颜色**：11 种纯色，“恢复默认”回到跟随背景预设。
  - 选了颜色后，标题栏图标和未选中的会话页签自动换成在该颜色上看得清的文字色（深色栏用浅字，浅色栏用深字）。
  - 切换背景预设不会覆盖已选的导航栏颜色。
- **系统字体**：列出本机已安装的字体，作用于除终端外的所有窗口，“默认”恢复平台字体。
  - 字体名只接受字母、数字、空格和少数标点。含逗号、`#`、`:`、`/` 等字符的名称会被拒绝：这类名称可能在排版时让程序报错，连设置窗口也打不开。
  - 已保存但本机没有的字体仍显示在列表里，不会悄悄消失。
- “恢复默认外观”只恢复外观相关设置，终端和本地终端设置保留。

### 通用终端

- **终端配色**：
  - 可选：跟随主题（默认，即之前的行为）、Studio 暗色、Studio 亮色、Solarized 暗色/亮色、Dracula、Nord、Gruvbox 暗色。
  - 下拉项带配色预览。已打开的终端立即换色，终端区背景也一起换；文字、光标颜色取自配色；选区用配色的蓝色半透明覆盖，保证选中的文字仍看得清。
  - 只有真正更换配色或明暗时才重设颜色，改别的设置不会抹掉程序自己设置的颜色（OSC 4/10/11）。
  - 配色数值采用各开源配色公开的取值。
- **终端字体**：只列出本机已安装的常见等宽字体。所选字体排在最前，内置等宽字体栈保留在后面作为缺字回退。

### 本地终端

- **默认程序参数**：
  - 按空格分隔，双引号可包含空格，引号内 `\"` 表示一个引号。除此之外什么都不解释：`$HOME`、`*`、`|`、反引号都原样传给程序。
  - macOS / Linux：结果作为参数数组直接交给程序，**不经过 shell**。
  - Windows：系统本身没有参数数组，所以把输入的文字原样附加到命令行（与快捷方式相同），由程序按自己的规则解析，也不额外经过 shell。不用 Porta.Pty 自带的转义，因为它会丢掉空参数、弄错末尾的反斜杠；也不自己重新加引号，因为那会改变 `cmd.exe` 等程序的含义（例如 `"C:\R&D"` 去掉引号后会变成两条命令）。
  - 输入框下方实时显示将传入的参数。以下情况不传参数并标红说明原因，本地终端照常打开，原因也显示在状态栏：
    - 引号没闭合等无法解析的文字。
    - 配置的默认程序找不到、改用系统默认 shell（参数本来是给另一个程序的）。
    - Windows 批处理程序（`.bat`/`.cmd`）：它的参数会被 cmd 解释，所以不传。
  - 含控制字符或超过 1024 字符的文字不会保存，输入框下方会写明，改好后再保存。
- **终端类型**：下拉选择本地终端的 TERM（xterm-256color、xterm、xterm-color、screen-256color、tmux-256color、vt100、linux），默认 xterm-256color。

### 修复

- **默认程序输入框无法在中间输入空格**（alpha.3 起就有）：输入框每打一个字就保存一次，保存时会去掉首尾空格，于是 `/Applications/My App` 里的空格刚打出来就被删掉。现在这两个文本设置保存时不去空格，用的时候再去。

### 修复（第二组，来自审查）

- **亮色终端文字发白、看不清**（第一轮审查发现，高危）：终端组件的模板把默认文字色写死为白色，并推进终端模拟器。亮色主题和新增的亮色配色下，终端里是白底白字；切换页签后又会变回白色。明亮主题下的这个问题更早的版本可能也有，没有回查。现在文字、背景、光标、选区颜色由配色直接指定。
- **设置保存失败会让程序退出**：数据目录不可写时，点预设等操作会抛出没人处理的异常。现在改为在设置窗口显示“设置已生效，但没有保存到磁盘”；标题栏切换明暗时在主窗口提示。
- **打开的设置窗口会覆盖别处的改动**：设置窗口记着打开时的旧值，之后在别处（标题栏切换明暗、另一个设置窗口）改的内容会被它改回去。现在始终以当前生效的设置为准，并且跟随别处的变化刷新。

## 未验证 / 限制

- 以下都没有运行过：Windows 实机（ConPTY、DPI、输入法）、真实控制器唤醒和堡垒机、Windows 凭据管理器和 Mac 钥匙串的真实读写。Windows CI 工作流仍未运行（代码没有提交推送）。截图都是软件渲染。
- **Windows 的默认程序参数没有在 Windows 上运行过**。依据是读 Porta.Pty 2.2.3 的实现（反射调用它的格式化函数、查看 IL），以及在 macOS 上核对传给它的内容。
- 默认程序参数只影响本地终端，不影响任何 SSH 会话。默认程序是 `cmd.exe` 时，参数由 cmd 自己解释，这是该程序本身的行为。
- 终端配色里的“选区”用统一算法取色，与各配色公开的选区颜色不同，因为终端组件把选区画在文字上面。
- 参考截图里没有做：背景色、自定义背景图片、全局不透明度 / 透明度；通用终端分类下的命令提示、会话记录、高级配置、右键菜单、自定义高亮；“SSH 服务”整个分类（快速命令、编辑配置、上传下载、文件管理、布局配置等）；本地终端的标签位置、标签渲染；按键配置、锁屏配置、备份恢复。账号、AI 助手、软件更新、推广、RDP、笔记按计划不做。
- **退回 alpha.4**：alpha.4 能读取设置文件，但它一旦保存设置，会丢掉本版新增的设置（导航栏颜色、字体、终端配色、本地终端参数和终端类型）。连接库格式没有变化。
- 连接库、隧道等其他限制见 `docs/STUDIO-ALPHA4-DELIVERY.md`。
