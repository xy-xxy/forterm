# 0.1.7 工作区与文件来源维护说明

终端工作区为左文件、中央终端/编辑、右监控；纯文件会话保留独立浏览，打开终端后进入同一工作区。最左连接/堡垒机导航为独立可折叠区域，不等同于文件标签。

## 文件绑定

- `FileWorkspaces` 在主进程内存保存明确引用，`sourceIds` 含本终端SFTP基座及外部来源，`activeId` 必须属于该组。最多32项（含基座），不匹配host/IP/user，不持久化临时会话。
- `attachFileSource` 明确追加并选中；`selectFileSource` 只切已有引用，允许查看已断线来源元数据而不建立连接；`detachFileSource` 只解除引用。草稿/排队或运行传输时解释确认，传输与文档不取消；干净引用直接解除。底层关闭仍走旧全局草稿/共享/传输保护。
- `linkFiles` 保留旧单来源替换语义及旧guard；`fileAssociations` 仍投影当前来源供兼容。新bootstrap/event另给`fileSourceGroups`/`file-sources`，旧映射可生成基座+原来源组，UI不依赖无绑定的外观标签。
- 顶部隐藏所有被明确引用的文件协议会话（含非活动源），只在最后引用移除后恢复；闭环旧引用保留可达入口。外部聚焦隐藏源直接转所属工作区并选中相应文件标签，不先渲染无关独立页面；隐藏源不参与双终端候选。
- 每个工作区/来源有固定key的FilePanel，隐藏保留目录/筛选/排序/滚动；隐藏不持续刷新，必要刷新到再显示时合并处理。关闭关联可销毁浏览面板，但文档仍按原工作区/来源/路径保存，切换/解除不自动保存或丢草稿。
- 编辑文档选择独立于浏览器活动源；同名文档按sourceId区分，标题可见来源，保存/重读/传输直接捕获原sessionId。来源B断线不会让来源A的保存错误禁用，也不向另一个会话写入。离线草稿仍能编辑，保存禁用。

## 布局及焦点

`forterm.layout.v1` 添加 navigationVisible/filesVisible/monitorVisible/filesWidth/monitorWidth；旧panel宽迁到文件宽，旧panel关闭状态兼容。保留旧编辑停靠/宽高/分屏比例字段与全局重置；有效尺寸按容器限制，首选值保留。中央不足时临时底部编辑，不改用户左右偏好；左右侧宽优先保留实际按钮所需宽度和非零终端空间。

来源列表在低高度使用自身可滚动视图及200px最小文件面板，避免150%+展开队列把行按钮挤成不可访问高度；不通过滚动隐藏根容器掩盖问题。工具栏保持单行且有左右箭头；选中来源标签仅滚动自身横向视口，不抢焦点或滚动根。

导航收起控制在品牌区域，展开控制为topbar固定子项，位于可横向滚动工具组之外。真实按钮支持Enter/Space，动作只改navigationVisible，保存首选sidebar宽；下一帧把焦点交给对应恢复/收起按钮。连接、来源、文档和监控开关不变，PTY按可见容器实时resize。

窗口/来源切换使用稳定文档缓存key，编辑器三向停靠不重建SSH或自动保存；来源页隐藏保留状态，监控页按visible停止/恢复用户开启的刷新且有在途防重叠。双终端选择和输入仍绑定实际可见会话，CtrlS在编辑器消费。

## 当前验证与限制

4项布局/旧来源迁移单元，三列/导航/100条控件可达性/剪贴板/综合工作区/入口与11进程定向UI通过；具体最终日志及包摘要见VALIDATION-0.1.7.md。Windows原生/生产现场尚待执行。厂商登录/资产provider仍为空，不能直接登录门户；本布局工作没有访问门户或猜接口。FTP不支持安全在线编辑与排他新建，双击只提示不自动下载。
