# Forterm Studio 0.4.0-alpha.7 交付说明（2026-11-24）

按用户 11-24 的要求做了三件事：监控重新设计；所有操作的动画做美观、操作更人性化；终端和内置编辑器加上关键字颜色。计划和决定见 `docs/STUDIO-REBUILD-PLAN.md`，上一版见 `docs/STUDIO-ALPHA6-DELIVERY.md`。

只改了 Studio（`avalonia/src/Forterm.Studio` 和它的测试）。Core、vendor、alpha.36（`Forterm.Desktop`）、alpha.6 及更早的包和检查点都没有改动。

## 内容

### 监控（重新设计，不再照搬截图）

- **先说结论**：最上面一行是“运行正常 / 几项严重、几项注意”，下面按严重程度列出原因（磁盘快满、可用内存不足、交换区、CPU 持续偏高、等待磁盘、被宿主机抢占、负载），点一条就跳到对应的卡片。
  - CPU、等待磁盘、抢占这类会跳动的值按一段时间的平均判断，一次偶发的高峰不会报警；手动刷新时，两次刷新之间的平均同样算数，说明里写明“近几分钟”。
  - 没读到数据时写“没有读到可用的数据”，CPU 还没有足够数据时写“暂无异常，CPU 观察中”，不会一上来就说正常。
- **总览**：CPU、内存、用得最满的磁盘、负载，四条固定位置的仪表，始终可见。
- **卡片**：CPU（趋势、用户 / 系统 / 等待磁盘 / 被抢占、每核占用）、内存、网络（含各网卡）、磁盘（最满的在前；磁盘百分比与 `df` 一致；光盘和 snap 镜像不算）、进程（按 CPU 或内存前 6）。
- **趋势图**：鼠标移到任意一张图上，所有图同时显示那一刻的数值；可以用键盘左右移动；没有读数的时间画成断开，不连线、不画成 0。
- **宽度**：侧栏约 280 像素为一列，拉宽后两列、三列；最大化时图变高。
- **选项**：刷新间隔（手动 / 3 / 10 / 30 秒）、趋势范围（3 / 10 / 30 分钟）、复制趋势数据（CSV）。
- 读取失败后停止自动刷新，数字变淡并显示“已暂停”，由用户点刷新恢复（堡垒机可能审计每一次请求）；进程管理窗口同样如此。
- 进程管理窗口改版：刷新时行的位置和选中项不跳动；可复制 PID 和命令。
- 读取方式不变：独立的只读通道，固定命令，不在终端里输入任何内容。图表颜色用色觉障碍模拟脚本核对过（深浅两套）。

### 动画

- 悬停和按下、页签出现、切换会话、菜单 / 下拉 / 提示、对话框、通知、树的展开箭头、仪表和进度条、连接等待、录制红点都有动画，时长 0.12–0.24 秒（仪表 0.45 秒）。
- 动画只改透明度、位置和颜色，**不改变终端大小、操作的结果和时机**；静止时不产生动画（原生窗口空闲 CPU 0–0.6%）。
- 系统配置 → 主题界面里有“界面动画”开关，关闭后一点不留。

### 操作

- **命令面板**（macOS `⌘K`，其他系统 `Ctrl+Shift+P`）：输入几个字就能切换会话、打开连接、执行快速命令、打开设置。它只做点击会做的事，该确认的照样确认；会话一变就关闭。
- **快捷键**：新建 / 关闭页签、切换会话、连接库、系统配置、查找、终端文字大小。都列在系统配置 → 快捷键。macOS 用 Cmd，其他系统的字母键用 Ctrl+Shift，不占用 shell 的 Ctrl 组合、AltGr 和 `Ctrl+_`。
  - 按住不放只算一次。控制器打开的会话不能重新打开，用快捷键关闭前会确认。终端栏没显示时不关闭看不见的终端。
- **焦点**：自己切换会话、新建页签、打开编辑器后，键盘直接跟过去；**控制器唤醒的会话不会抢走键盘**，正在输入的内容不会跑到新会话里。
- **通知**：传输完成或失败、复制、后台会话断开等会在右下角提示，可以点“打开文件夹”“查看”；鼠标停在上面不消失。
- **拖放上传**：把本机文件、文件夹拖到文件栏，显示将要上传到的目录；与菜单上传走同一套检查和确认。一项被拒绝不影响其他项，并逐项说明原因。
- 文件列表 F2 重命名、Delete 删除（有确认）、F5 刷新、Enter 打开；鼠标中键关闭页签；标签栏可用滚轮横移；Cmd / Ctrl + 滚轮改变终端文字大小；栏宽会记住，双击分隔条恢复默认。
- **危险操作的确认窗口**默认焦点在“取消”，回车不会确认。

### 关键字颜色：终端

- 默认规则由 6 条增加到 14 条：新增日期时间、日志级别、`用户@主机`、命令、命令选项、路径、引号内容、百分比和大小。
- 仍在系统配置 → 自定义高亮里增删改、排序、停用；规则里写 `(?<k>…)` 可以只给一部分上色。
- 没改过规则的用户自动得到新规则；**改过的保留自己的，点“恢复默认”才会换成新的**。
- 只影响显示，限制与 alpha.6 相同（程序自己上过色的文字不改，全屏程序不改）。每行耗时：400 列的各种刁难内容平均最多 0.32 毫秒（审查代理测量）。

### 关键字颜色：内置编辑器

- 识别 29 种语言：Shell、YAML、JSON、INI / 各种 conf、TOML、Nginx、Dockerfile、Makefile、日志、SQL、XML、HTML、CSS、JavaScript / TypeScript、Python、Java / Kotlin、Go、Rust、C / C++、C#、PHP、Ruby、Perl、Lua、PowerShell、Markdown、补丁、Crontab、Hosts。
- 按文件名、所在目录（`/etc/nginx/`、`/var/log/` 等）、扩展名、首行判断；`nginx.conf.bak`、`app.log.1` 这类也认得。工具栏可以手动改。
- 背景、文字、选区、行号和各类关键字的颜色都取自终端配色，换配色或明暗主题时一起换；每种颜色都调到能看清为止（测试逐个配色、逐种语言核对对比度）。
- **服务器给的文件不能卡住窗口**：规则都有长度上限，每次匹配有时间上限；着色太慢或有超过 1 万字符的行时，只关闭这个文件的着色并说明，内容不受影响。

- **变异检查**：在副本里逐个故意改坏 119 处，114 处被测试发现。没被发现的 5 处各有另一道判断兜住，改坏后没有可见差别：`df-again` 与 `df-header`（互为冗余）、`focus-wanted`、`focus-first`、`ec-once`。

  - 第二轮变异检查跑到 39 处时代码又有改动，停掉后在新代码上重跑了其余部分。

## 未验证 / 限制

- 以下都没有运行过：Windows 实机（ConPTY、DPI、输入法、AltGr、触摸板、真实拖放）、真实控制器唤醒和堡垒机、真实 OpenSSH / GNU `df`、Windows 凭据管理器和 Mac 钥匙串的真实读写、屏幕阅读器。Windows CI 工作流仍未运行（代码没有提交推送）。
- **命令面板和中文输入法**：正在组字时，回车、方向键先给输入法；这一点只按代码处理，没有用真实输入法试过。
- 编辑器着色是按行的正则，不是语法分析：跨行的 YAML 块、heredoc 等只能近似；TypeScript 用 JavaScript 的规则，Kotlin 用 Java 的规则。
- 编辑器里手动选的语言不保存，重新打开文件时重新识别。
- 终端的“命令”规则只认常见的提示符样子（`$`、`#`、`%`、`❯`、`➜`）；单独一个 `#` 开头的行按注释处理，不当作命令。
- 监控的结论是固定阈值（磁盘 85% / 95%、CPU 85% / 95%、可用内存 10% / 5%、负载为核数 2 倍 / 4 倍等），还不能自己设置。
- **退回 alpha.6**：alpha.6 能读取设置文件，但一旦保存会丢掉本版新增的设置；超过 30 条或 200 字符的高亮规则会被它截断。连接库和快速命令的格式没有变化。
- 其他限制见 `docs/STUDIO-ALPHA4-DELIVERY.md` 到 `docs/STUDIO-ALPHA6-DELIVERY.md`。
