# Forterm 0.1.2

2026-10-24 · Windows 10/11 x64

## 本次更新

- 同一 SSH 会话中使用终端、文件管理、在线编辑与资源监控，复用连接和认证。Xftp 入口也可按需打开终端；通道被拒绝时保留其他可用通道。
- 在线编辑最多 12 个 UTF-8 文件，每个不超过 1 MiB；拒绝二进制和符号链接，支持 BOM、CRLF。显式保存、内容摘要冲突检测、0600 临时文件写入、恢复原普通权限后替换，以及未保存文件的关闭确认；断线保留窗口内草稿。
- 默认 15 秒 SSH 协议保活、已有 SFTP 通道只读探测；设置持久化，新会话生效，无终端自动输入。
- 文件筛选、排序、路径导航、隐藏文件；传输取消和已结束记录清理。
- 同会话监控手动刷新或主动开启每 10 秒刷新，隐藏后停止新请求；区分负载、累计计数与使用率。
- 主题、字号、侧栏与分组折叠持久化；快捷键帮助；上下/左右双终端分屏并选择分屏会话。
- 保留 0.1.1 的精确参数转交、三秒同票据去重、内存临时凭据、多轮认证、指纹核对与系统加密能力。

## 使用与升级

退出旧版，解压新版 ZIP 到独立目录，将控制器路径改为新目录中的 `xshell.exe` / `xftp.exe`。完整目录包含 `forterm.exe`、`xshell.exe`、`xftp.exe`、`forterm-diagnose.exe` 四个入口；不能只复制单个入口。

SSH 进入后点击“打开文件浏览”；Xftp 进入后点击“在此会话打开终端”。右侧“同时显示”放置文件与监控，文件行的在线编辑按钮打开下方编辑器。

## 已知边界

- 心跳不能保证阻止服务器强制会话时限、shell 空闲退出或系统休眠断线。
- 编辑仅支持 UTF-8 普通文本，草稿仅存于内存，强制终止应用会丢失。保存需要目录写权限和服务器支持替换；失败时不删除原文件来强行覆盖。
- 保存前进行两次内容/元数据检查；SFTP 不提供通用的原子条件替换，最终检查与替换间有短暂竞争窗口。保存不承诺保留原所有者、ACL、扩展属性或硬链接关系；断线可能遗留远程临时文件。
- 监控面向有 `/proc` 与 `df` 的 Linux；堡垒机禁止命令通道时给出提示。展示 CPU/网络累计值，不把它们误标成即时占用率或速率。
- 当前开发机为 macOS。Windows 包为交叉构建，新增功能的 Windows 实际运行与生产堡垒机权限仍需现场验收。应用未签名，未上传发布。
