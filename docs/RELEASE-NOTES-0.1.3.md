# Forterm 0.1.3

2026-10-26 · Windows 10/11 x64

## 可拖动工作区

- 连接栏宽度、文件/监控侧栏宽度、下方编辑器高度均可拖动。
- 文件与监控同时显示时可调整上下比例；双终端上下、左右分屏分别记住比例。
- 拖动时实时适配 xterm 和远端 PTY，限制最小区域和窗口收缩边界；放大窗口后恢复偏好尺寸。
- 分隔条支持 Tab 聚焦、方向键调整、Shift 加速、Home/End 到最小/最大。Enter 或双击重置当前分隔条，顶部“重置布局”恢复默认尺寸。
- 布局保存在本机；正常关闭时立即保存最后一次调整。拖动不触发命令、保存文件或再次认证。

## 交互与修复

- 编辑器可收起而保留未保存草稿，展开恢复原高度。
- 切换文件/监控或收起右栏时保留文件导航、筛选和监控开关；自动监控隐藏暂停、展开恢复，保持防重叠。
- 修复慢速 shell 打开时，首次终端尺寸可能在通道就绪前丢失的问题；250ms 延迟回环服务验证通道就绪后主动同步尺寸。
- 完善 pointer capture、cancel、失焦和窗口级松手清理，防止拖动状态残留；大文本字节数缓存，避免拖动时重复编码整份文件。
- 纯 Xftp 查看同会话监控时不再产生空白文件区；终端、文件、在线编辑和监控仍复用同一已认证 SSH transport。

## 兼容与升级

退出旧版，将新版 ZIP 解压到独立目录，控制器路径选择新版 `xshell.exe` / `xftp.exe`。完整目录保留 `forterm.exe`、`xshell.exe`、`xftp.exe`、`forterm-diagnose.exe` 四个入口，不能只复制单个 exe。

保留 0.1.2 的默认 15 秒可配置心跳、文件编辑冲突检查、未保存保护、系统加密与通道拒绝隔离；保留 Xshell/Xftp 精确参数转交、同票据重复启动去重、临时凭据仅内存和不自动重连临时票据。

## 验证与边界

本机 34 项单元/回环协议测试、桌面 smoke、统一工作区、真实指针布局测试及 11 进程 burst 通过。布局测试覆盖五类拖动、捕获取消/重用、键盘和重置、重启持久化、真实 SSH 窗口尺寸、草稿与输入隔离、隐藏监控暂停恢复、传输队列、1050×650 最小窗口和 125% 页面缩放。

开发机为 macOS；Windows 三种包为交叉构建并进行静态完整性核验，新增 Windows 拖动、ConPTY 与真实堡垒机现场验收仍待用户完成。没有上传发布或运行远程 CI，应用未签名。

客户端内置堡垒机登录与资产选择尚待厂商/版本及官方接口契约；当前支持用户已验证的网页授权 + 控制器启动方式。未读取历史真实票据或重放生产登录接口。心跳不能消除服务器强制时限；在线编辑保留原有大小、编码、权限和并发竞争边界，详见 README。
