# 堡垒机接入基础：0.1.6-dev.1

2026-10-26。这里是可测试的主进程接入基础，**不是厂商登录/资产已经接通**。生产注册表为空；用户账户一律显示“待适配”，不访问配置的入口、不显示假资产。本基础已随0.1.6阶段版一同打包，界面仍待适配；0.1.5发行包保留且未重打。

## 代码与信任边界

- `src/main/bastion-provider.ts`：厂商适配器契约。login / respond / assets / request / approval / exchange / cancel / logout / dispose。具体方法、路径、身份载体及字段映射必须来自同产品/版本的契约，不能套用猜测的华为云接口。
- `src/main/bastion-service.ts`：身份、挑战、审批、兑换及连接生命周期。只接收主进程构造的提供器，不内置HTTP请求、不接受renderer传来的URL/Header/原始body或通用代理指令。
- `src/shared/bastion-access.ts`、主进程IPC和preload：只暴露状态及显式操作。当前本地账户ID、随机资产/账号引用、随机分页引用、申请ID和会话ID；不暴露门户身份句柄、厂商资产ID、原sid、Cookie/Token、授权票据或临时SSH密码。
- `Store.withBastionPassword`：仅主进程回调临时使用系统解密密码，解密后重新核对配置版本，配置被改/删则拒绝调用；错误脱敏，无新IPC返回密码。手动输入只用于本次，不自动保存。TOTP沿用已验证实现，只在主动提交时计算；窗口活跃性在解密后、提交前再次检查。
- `src/renderer/BastionAccessPanel.tsx`：接入状态和受限登录/MFA/授权资产/账号协议/审批操作界面。真实提供器缺失时登录禁用，后续表单/资产均不伪造；生产未提供合成模式或配置开关。

仅主进程适配器可持有认证上下文。门户长期密码用于门户登录，绝不作为SSH参数兜底；sid也不拼接为SSH URL。临时连接描述必须明确返回协议、地址、端口、临时账号/密码和有效期，协议必须匹配用户所选授权引用。字段显式传给现有 `Sessions.connect`，`temporary=true`，不进入Store、导出或报告。当前描述仅支持SSH/SFTP临时密码；私钥/证书、特殊加密blob、工具/SDK兑换均待明确契约，不能宣称已支持。

## 状态与并发规则

| 层 | 状态与判定 |
| --- | --- |
| 账户接入 | unavailable / signed-out / authenticating / mfa / authenticated / expired / unknown / error。只有适配器确认身份才authenticated，不以HTTP200或拿到sid替代 |
| MFA | 本地随机challenge ref绑定当前账户身份代次及过期时间；手动或主动使用已配置TOTP二选一，不自动提交。browser挑战只说明需要受支持的隔离网页登录，尚未实现打开远程登录页 |
| 资产 | 查询/分页来自当前身份；renderer的asset/account/cursor引用映射回主进程内部句柄，不接受任意外部ID。跨资产、协议未授权、跨查询游标及注销/配置变化后的旧引用拒绝 |
| 申请 | requesting → pending-approval / denied；pending仅由主动刷新查询，不重新申请。approved在内部立即进入exchanging，消息明确已批准 |
| 一次性兑换 | 每申请最多一次，兑换前标记已发起。超时、网络中断、取消时结果可能未知；unknown锁定该身份代次/选择的重复点击，不盲目重放 |
| 连接 | connecting不代表可用。SSH须真实terminalStatus=ready，SFTP须实际通道成功；通道拒绝给出说明并保留其他能力。用户关闭连接立即更新申请状态 |
| 结束 | ready / denied / cancelled / expired / unknown / error。cancelled指本地取消，只有契约明确的服务端撤销ack才显示“服务端已确认”；超时不声称远端回滚 |

登录和MFA在途合并；同账户/身份代次/资产/账号/协议的会话申请在途返回同一ID。分页查询不重叠，旧身份的晚到结果丢弃。默认每提供器调用15秒，连接等待60秒；没有自动网络重试、刷新身份、再次审批或再次兑换。挑战/身份/待审批授权到期使用本地计时器清理，不发网络请求。

注销先撤掉本地身份、引用和未完成的门户操作，再按契约尝试服务端注销；未确认的服务端结果如实提示。已经认证的SSH transport保留，包括终端尚在打开但其他能力可能已被用户使用的情况；未认证连接尝试可停止。用户若需关闭已认证会话，仍通过原会话关闭流程处理草稿/传输确认。关闭门户身份不自动退出所有SSH，也不自动重用票据。已经打开的SSH保活继续使用原transport。

资源边界：每页最多200资产、每资产100账号、每身份累计2000资产引用与128分页引用；超出拒绝而不伪造截断结果。最多100条申请记录，优先清理已结束且非unknown记录，未处理unknown过多时拒绝新增。JavaScript字符串不能保证物理内存擦除；本实现清除引用/临时字段并由适配器dispose清理自己的句柄，秘密仅在主进程内存，不能声称物理零化。

## 未来网页登录的隔离设计（尚未创建窗口）

若实际契约要求网页登录，应新建不持久化partition的受限窗口/视图，**无preload、nodeIntegration=false、contextIsolation=true、sandbox=true、webSecurity=true**，不加入拥有Forterm IPC权限的本地窗口集合。不能在当前带 `forterm` preload 的窗口直接 loadURL 门户。

适配器必须根据官方跳转链确定入口/IDP/回调的精确origin白名单，同时限制导航、重定向、新窗口、下载、外部协议和权限；使用正常TLS校验，不关闭证书检查或注入抓包根证书。独立内存Cookie/session，不共用本地工作区或系统浏览器的旧Cookie；注销/关闭清理存储和句柄。认证回调需校验nonce/state/有效期和发起实例，主进程只按已核实字段完成身份确认，不向远程页注入通用IPC，也不按任意页面消息执行命令。对未知SSO跨域跳转先等待契约，不靠扩大白名单绕过。

依据：[Electron官方安全指南](https://www.electronjs.org/docs/latest/tutorial/security)。此段是后续设计约束，不代表已实现嵌入式登录或任何厂商Web流程。
